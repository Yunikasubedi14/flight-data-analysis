\# Flight Data Analysis \& Visualization System



A Python-based flight data analysis and visualization system that processes CSV datasets to generate useful statistics about flights, airlines, delays, destinations, distances, weather conditions, and hourly flight activity.



\## Project Overview



This project was developed as an academic coursework project to demonstrate practical Python programming, file handling, data processing, validation, and data visualization.



The application allows users to select an airport and year, analyze the corresponding flight dataset, and generate statistical results. It also provides an interactive histogram showing the number of flights operated by a selected airline across different hours of the day.



\## Features



\- Airport code validation

\- Airline code validation

\- Year selection and dataset loading

\- CSV file processing

\- Flight statistics and analysis

\- Airline performance analysis

\- Delay analysis

\- Flight distance analysis

\- Weather condition analysis

\- Destination frequency analysis

\## How to Run



\### 1. Clone the repository



```bash

git clone https://github.com/Yunikasubedi14/flight-data-analysis.git

```



\### 2. Navigate to the project directory



```bash

cd flight-data-analysis

```



\### 3. Run the program



```bash

python Main.py

```



\### 4. Follow the prompts



The program will ask for:



1\. A three-letter airport code

2\. A year

3\. An airline code for the histogram



The program will then process the corresponding CSV dataset, display the analysis results, save results to `results.txt`, and generate an interactive histogram.



\## Example



```text

Please enter a three-letter city code: LHR

Please enter a year: 2025

```



After the flight analysis is completed, the program asks for an airline code and generates a histogram showing hourly flight activity.
